Ersteinrichtung

Dein Browser unterstützt die File System Access API nicht. Bitte nutze Google Chrome oder Microsoft Edge, um dieses Tool zu verwenden.

Wähle eine bestehende JSON-Datei aus oder erstelle eine neue leere Datei (z. B. in deinem Dokumente-Ordner). Diese Datei wird ab sofort von Chrome und Edge gemeinsam genutzt, damit alle Einträge und Einstellungen synchron sind. Später kannst du über „+ Datei" im Kopfbereich weitere Dateien (z. B. für andere Mitarbeiter) hinzufügen und zwischen ihnen wechseln.

Diese Seite kennt bereits eine Datei, benötigt aber deine Bestätigung für den Zugriff (Sicherheitsvorgabe des Browsers).

Einstellungen
